# ETF 不定期定額觀察器

一個適合手機使用的 PWA，用來管理 ETF「有便宜才買、沒便宜就留現金」的不定期定額策略。

## 核心功能

- ETF 觀察清單
- 近期高點回撤計算
- 🟢 -3%～-5%：小額買
- 🟡 -5%～-10%：加碼
- 🔵 -10%～-15%：較大額加碼
- 🔴 ≤ -15%：動用預備資金
- ⚪ 0～-3%：不追價
- NT$10,000 月度可用資金管理
- NT$36,000 年度現金流目標
- 持有股數與價格紀錄
- localStorage 儲存
- GitHub Pages / iPhone「加入主畫面」可用

> 本專案目前是「策略與資料管理工具」，價格資料需由使用者更新；不代表即時行情，也不是投資保證。

## GitHub Pages 部署

1. 在 GitHub 建立新的 Repository，例如 `ETF-DCA-Radar`
2. 將本資料夾內所有檔案上傳到 Repository 根目錄
3. 進入 **Settings → Pages**
4. Source 選 **Deploy from a branch**
5. Branch 選 `main` / `root`
6. 儲存後等待 GitHub Pages 建置
7. 用 iPhone Safari 開啟 Pages 網址
8. 選「分享 → 加入主畫面」
